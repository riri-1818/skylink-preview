Canva Create in Sydney レポート

Productivity × Creativity が切り拓く、これからの働き方と創造性

2025年、Canva が主催するグローバルイベントCanva Create in Sydney 2025 に、今年も Canva Empower Canvassador としてご招待いただきました。

世界中のクリエイター、教育者、起業家が集まるこのイベントは、Canvaが描く 「誰もが創造できる世界」 の“今”と“これから”、そして最新機能を体感できる特別な場です。

Canva Create 2025 のテーマ

Productivity × Creativity（生産性 × 創造性）

今回のCanva Createで一貫して伝えられていたのは、生産性と創造性は、トレードオフではない という明確なメッセージでした。

Canvaが新たに発表した 40以上の新機能 は、すべて実際のユーザーの声を起点に開発されたもの。

「こんな機能がほしい」その声が、確実にプロダクトへと反映されていました。

注目のCanva新機能（2025）

Magic Write

AIがキャッチコピーや文章を瞬時に生成

Magic Media

テキストプロンプトから画像・動画を自動生成

Canva Sheets

スプレッドシートから複数デザインを一括作成

Canva Code

ノーコードでウィジェットを作成

AI Photo Editor

ワンクリックで背景除去・差し替え

All-in-one Workspace

デザイン・テキスト・データを1ファイルに統合

これらの進化は、単なる「時短ツール」ではありません。一人ひとりの表現力と可能性を解放するための進化だと、強く感じました。

オンライン時代だからこそ、リアルな場の価値

誰とでも簡単につながれるオンライン時代だからこそ、このような リアルなイベントやコミュニティ の価値は、より深まっています。

Canva Create in Sydneyは、テクノロジーと人、創造性と想いが交差する、温度のある空間でした。

Canvaへの感謝、そしてWomen Can Fly（WCF）のこれから

Women Can Fly（WCF） では、留学・海外キャリアに挑戦する方々が、

  • 自分の考えを

  • 自分の言葉で

  • 世界に向けて発信する

その力を育てることを大切にしています。

Canvaは、英語力やデザイン経験に関係なく、「表現すること」へのハードルを下げてくれる存在。

WCFの現場でも、Canvaを通じて自信を取り戻し、前に進む学生や社会人を数多く見てきました。

Canvaイベントチームの皆さま、今回も心からインスパイアされる場をありがとうございました。

そして、Women Can Fly.Co (WCF)の活動を支えてくれているWCFチーム、コミュニティの皆さんにも感謝を込めて。

WCFはこれからも、創造性を武器に、世界へ挑戦する人を応援し続けます。
